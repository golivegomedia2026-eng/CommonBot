# CommonBot 使い方

CommonBot は、自分のマシン上でエージェントを作るためのソフトです。担当する仕事を決め、資料を与えてそれに基づいて答えさせ、必要なら Web も検索させられます。「ビルダー」と対話して新しいエージェントを定義し、他の人に公開することもできます。データはすべて自分のマシンに保存されます。

## 1. インストールと起動

### Spark などの Linux マシン

1. パッケージを展開し、フォルダーに入ります。
2. `./commonbot` を実行し、そのマシンのブラウザーで `http://localhost:8600` を開きます。
3. 起動時に自動で動かすには `sudo ./install.sh` を実行します。プログラムが `/opt/commonbot` に入り、現在のユーザーで動くシステムサービスとして登録されます。削除は `sudo /opt/commonbot/uninstall.sh` です。データは削除されません。

ディスプレイのないマシンでは、ターミナルで LAN アクセスをオンにし、表示されたアクセスコードを控えて、別の端末から使います（8 章参照）。

```
./commonbot --lan on
```

（`install.sh` でサービスとして入れた場合は `/opt/commonbot/commonbot --lan on` を実行し、続けて `sudo systemctl restart commonbot` を実行します。）

### Mac

1. パッケージを展開します。
2. 初回のみ、ターミナルで展開したフォルダーに対して次を実行します（署名のないプログラムのため、実行しないと macOS が起動を拒否します）：`xattr -dr com.apple.quarantine フォルダーのパス`
3. フォルダー内の「Start CommonBot.command」をダブルクリックします。ブラウザーが自動で開きます。

### デスクトップ版（任意）

上のアーカイブのほかに、ウィンドウ付きのデスクトップ版があります。Linux は `.deb`（`sudo apt install ./CommonBot_バージョン_arm64.deb`）、Mac は `.dmg` です。起動するとバックグラウンドでサービスを動かし、画面を表示します。ウィンドウを閉じてもサービスは動き続けます。終了するにはトレイアイコンのメニューを使います。データはアーカイブ版と同じ場所に保存されるので切り替えて使えますが、両方を同時に動かさないでください。

## 2. モデルの準備

CommonBot にモデルは含まれていません。マシン上の推論サービスに接続して使います。もっとも簡単なのは Ollama で、インストールしてモデルを取得すれば、CommonBot は既定でそれに接続します（`http://127.0.0.1:11434/v1`）。OpenAI 互換 API を持つサービス（vLLM、llama.cpp など）も使えます。「モデル」ページで追加してください。

次の 3 種類を用意すると便利です。

| 用途 | 説明 | ない場合 |
| --- | --- | --- |
| 対話モデル | 必須。回答とビルダーに使います | チャットできません |
| ベクトル化モデル | ナレッジベースを意味で検索できるようにします（例：bge-m3） | キーワード検索のみ |
| 画像を読めるモデル | スキャン文書や画像の文字を読み取ります | スキャン文書・画像を読めません |

### いちばん簡単：画面からワンクリックでダウンロード

マシンがインターネットに接続でき、まだ推論サービスが入っていない場合は、「モデル」ページを開きます。いちばん上の「ローカル計算：ワンクリックでダウンロード」で必要なモデルにチェックを入れ、「ダウンロードして有効にする」を押します。推論ランタイムとモデルが自動でダウンロードされ、進み具合が表示されます。完了するとランタイムが起動し、対話・ベクトル化・画像の各モデルが割り当てられます。

- 既定の 4 つのモデルは合計約 35 GB（メモリー 48 GB 向けに選定）で、ほかにランタイムが必要です。不要なものはチェックを外してください。
- いつでも一時停止できます。回線が切れたり電源を切ったりしても、あとで「ダウンロードを続ける」を押せば続きから再開します。ファイルはダウンロード後に毎回検証されます。
- ダウンロードした内容は、データのフォルダーの `compute` に保存されます（9 章参照）。
- CommonBot を動かしているマシンでのみ操作できます。
- 別のモデルを使うには、起動前に環境変数 `COMMONBOT_COMPUTE_MODELS` を設定します。例：`chat=qwen3:8b,embed=bge-m3`

### 計算パック：推論サービスとモデルをまとめてオフラインで入れる

Ollama のインストールやモデルの取得を自分で行いたくない場合は、「計算パック」を使えます。`compute` という名前のフォルダーで、推論ランタイムと選定済みのモデル一式が入っています。CommonBot は起動時にこれを見つけるとランタイムを自動で起動し、対話・ベクトル化・画像の各モデルを割り当てます。ネットワークも追加の設定も不要です。

`compute` フォルダーを次のどちらかに置きます。

- `commonbot` プログラムと同じフォルダー（Linux では置いてから `sudo ./install.sh` を実行すると、`/opt/commonbot` に一緒に入ります）
- データのフォルダー（9 章参照。デスクトップ版はこちらを使います）

既定の一式は約 35 GB で、メモリー 48 GB のマシン向けに選んであります。日常の対話に qwen3:14b、より高性能な予備に qwen3:30b、ベクトル化に bge-m3、画像に qwen2.5vl:7b です。「モデル」ページのいちばん上にパックの状態が表示されます。すでに Ollama が動いているマシンでは、CommonBot はそれをそのまま使い、もう 1 つ起動することはありません。ランタイムのログはデータのフォルダーの `logs/compute.log` です。

計算パックは、配布する人がインターネットに接続できるマシンで作成します（ソースの `scripts/compute-pack.sh`）。別のモデルを入れることもできます。

### インターネットに接続できない場合

インターネットに接続できるマシンで Ollama を使ってモデルを取得し、モデルのディレクトリーをまるごと、このマシンの同じ場所にコピーします。

- Linux：`/usr/share/ollama/.ollama/models`（サービスとしてインストールした場合）または `~/.ollama/models`
- Mac：`~/.ollama/models`

Ollama を再起動し、CommonBot の「モデル」ページで「今すぐ確認」を押すと表示されます。

## 3. 最初の設定

「モデル」ページを開きます。

1. 上部に推論サービスの一覧があります。「正常」とモデル数が表示されていれば使えます。接続できない場合は、サービスが起動しているか、アドレスが正しいかを確認してください。
2. 「ナレッジベース用のモデル」で、ベクトル化モデルと文字認識モデルを選びます（まだなければ後でも構いません）。
3. Web 検索は既定で内蔵の検索を使い、設定は不要です。「試しに検索」を押すと、このマシンのネットワークで結果が得られるか確認できます。自前の SearXNG やキー付きの検索 API に切り替えることもできます。
4. ローカルのモデルが使えないときの予備が欲しい場合は、「推論サービスを追加」で種類を「クラウド」にし、アドレス、キー、既定のモデルを入力します。

## 4. エージェント

「エージェント」ページに一覧が表示されます。クリックするとチャットが開き、右上の「設定」で定義を変更できます。

- **担当する仕事 / 担当しない範囲**：具体的に書くほど、決めたとおりに動きます。担当外の質問には、その旨をはっきり伝えます。
- **参照する範囲**：既定で検索するナレッジベースのフォルダーです。
- **回答の根拠**：Web を使わない / ナレッジ優先、足りなければ Web / 毎回 Web を検索。
- **モデル**：特定のモデルに固定できます。固定しない場合はチャットで選んだモデルを使います。
- **最初のひとこと、質問の例**：新しいチャットに表示されます。例をクリックするとそのまま質問できます。

入力欄の下で、ファイルの添付（そのチャットだけで使い、ナレッジベースには入りません）、今回検索するフォルダーの変更、Web 検索のオン・オフ、モデルの変更ができます。回答中の小さな数字は出典の番号で、クリックすると元の文章を確認できます。

## 5. 対話でエージェントを作る（ビルダー）

1. 「ビルダー」を開き、「始める」を押します。
2. 質問に答えます。誰が使うか、どんな問題を解決するか、どの資料に基づくか、してはいけないこと、口調や形式など。サンプルや既存の応対文を添付できます。
3. 右側の下書きが会話に合わせて自動で埋まります。違うところはビルダーに伝えるか、「編集」を押して直します。自分で直した内容が、あとでビルダーに上書きされることはありません。
4. 「試し回答を始める」を押すと、ビルダーが質問を作り、下書きのエージェントに答えさせて、内容を判定します。納得がいくまで調整して繰り返せます。
5. 「エージェントとして公開」を押します。「エージェント」ページに追加され、専用のリンクと API キーが発行されます。

## 6. ナレッジベース

「ナレッジ」ページの左側がフォルダーで、階層にできます。まずナレッジベースを作成し、その中にサブフォルダーを作って文書をアップロードします。

- 対応形式：PDF、Word（docx）、PowerPoint（pptx）、Excel、テキスト、Markdown、Web ページ、画像。旧形式の doc・ppt と圧縮ファイルには対応していません。
- アップロードした文書はバックグラウンドで順番に処理されます。進み具合は表で確認でき、失敗した場合は理由が表示され、再試行できます。
- スキャン文書には、「モデル」ページで文字認識モデルを選んでおく必要があります。モデルがなくて失敗した文書は、選んだあと自動で処理し直されます。
- 「検索テスト」で、質問に対してどの断片が見つかるかを確認できます。
- 「このフォルダーの中だけで質問」で、現在のフォルダー（サブフォルダーを含む）だけを対象に質問できます。

ナレッジベースに根拠が見つからない場合、エージェントは作り話をせず、見つからなかったと答えます。

## 7. 他の人に公開する

エージェントの「設定」のいちばん下で「公開」を押します（先にモデルを固定しておく必要があります）。公開すると次のものが発行されます。

- **リンク**：開いた人はこのエージェントとチャットできます。アクセスコードは不要で、あなたの他の内容は見えません。
- **API キーとアドレス**：OpenAI 互換の API です。既存のクライアントやプログラムからそのまま利用できます。例：

```
curl http://ホストのアドレス:8600/v1/chat/completions \
  -H "Authorization: Bearer あなたのキー" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"こんにちは"}]}'
```

「公開を取り消す」と、リンクとキーはすぐに無効になります。「キーを再発行」は古いキーだけを無効にします。他の端末からリンクや API を使うには、LAN アクセスをオンにしてください（次章）。

## 8. 他の端末から使う

既定では、このマシンだけが CommonBot を使えます。「システムと外観」で「他の端末からのアクセスを許可」をオンにすると、アクセス用のアドレスが表示されます。他のパソコンやスマートフォンのブラウザーでそのアドレスを開き、初回だけアクセスコードを入力します。

アクセスコードの表示と変更は、「システムと外観」で、CommonBot を動かしているマシンでのみ行えます。変更すると、他の端末は入力し直す必要があります。

## 9. データの場所とバックアップ

データはすべて 1 つのフォルダーにあります。

- Linux：`~/.local/share/CommonBot`
- Mac：`~/Library/Application Support/CommonBot`

`commonbot.db` にエージェント、チャット、ナレッジベースの内容が、`files` にアップロードした元の文書が入っています。バックアップするときは CommonBot を終了してから、フォルダーごとコピーします。復元するときは元の場所に戻します。起動時に `--data-dir` を付けると、別の場所を使えます。

## 10. アップグレード

新しいパッケージをダウンロードし、古いバージョンを終了して、プログラムのファイルを置き換えます（Linux では `sudo ./install.sh` をもう一度実行します）。データのフォルダーはそのままで構いません。新しいバージョンがデータを自動で更新します。新しいバージョンが書き込んだデータを、古いプログラムで開かないでください。

## 11. 困ったときは

- **モデルサービスに接続できない**：Ollama などのサービスが動いているか確認し、「モデル」ページで「今すぐ確認」を押してください。
- **回答が遅い**：大きなモデルは文字を出すのに時間がかかります。日常の質問には小さめのモデルを使ってください。
- **PDF を登録できない（PDF エンジンが見つからない）**：パッケージの `lib` フォルダーを、プログラムと同じ場所に置いてください。
- **スマートフォンで開けない**：「他の端末からのアクセスを許可」がオンになっているか、スマートフォンが同じネットワークにあるか、ページに表示されたアドレスを使っているかを確認してください。
- **アクセスコードを忘れた**：ホストで「システムと外観」を開くか、ターミナルで `./commonbot --access-code` を実行してください。
