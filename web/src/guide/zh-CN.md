# CommonBot 使用说明

CommonBot 让你在自己的机器上建立智能体：给它定义负责的任务，给它资料让它照着回答，需要时让它联网；也可以通过和「建造师」对话，把一个新的智能体定义出来并发布给别人用。所有数据都存在你自己的机器上。

## 1. 安装与启动

### Spark 或其他 Linux 机器

1. 解压安装包，进入解压出的文件夹。
2. 直接运行：`./commonbot`，然后在这台机器的浏览器里打开 `http://localhost:8600`。
3. 想让它开机自动运行：`sudo ./install.sh`。它会把程序装到 `/opt/commonbot`，并登记为系统服务（以你当前的用户身份运行）。卸载用 `sudo /opt/commonbot/uninstall.sh`，你的数据不会被删除。

机器没有接显示器时，在终端里打开局域网访问并查看访问码，然后从别的设备访问（见第 8 节）：

```
./commonbot --lan on
```

（用 `install.sh` 装成服务后，改用 `/opt/commonbot/commonbot --lan on`，再执行 `sudo systemctl restart commonbot`。）

### Mac

1. 解压安装包。
2. 第一次使用前，在「终端」里对解压出的文件夹执行一次（否则系统会因为程序没有签名而拒绝打开）：`xattr -dr com.apple.quarantine 文件夹路径`
3. 双击文件夹里的「Start CommonBot.command」，浏览器会自动打开。

### 桌面版（可选）

除了上面的压缩包，还有带窗口的桌面版：Linux 是 `.deb`（`sudo apt install ./CommonBot_版本_arm64.deb`），Mac 是 `.dmg`。打开后它自己在后台运行服务并显示界面；关掉窗口后服务继续运行，从托盘图标的菜单里退出。数据和压缩包版本放在同一个位置，两种用法可以互换，但不要同时运行两份。

## 2. 准备模型

CommonBot 自己不带模型，它连接你机器上的推理服务。最省事的是 Ollama：装好后拉取模型即可，CommonBot 默认就连它（`http://127.0.0.1:11434/v1`）。vLLM、llama.cpp 等任何提供 OpenAI 兼容接口的服务也可以，在「模型」页添加。

建议准备三类模型：

| 用途 | 说明 | 没有它时 |
| --- | --- | --- |
| 对话模型 | 必需。回答问题、建造师都靠它 | 无法对话 |
| 向量化模型 | 让知识库能「按意思」检索，例如 bge-m3 | 只能按关键词检索 |
| 看图模型 | 识别扫描件和图片里的文字 | 扫描件、图片无法读取 |

### 算力包：连推理服务和模型一起离线装好

不想自己装 Ollama、拉模型的话，可以用「算力包」：一个名为 `compute` 的文件夹，里面是推理运行时和一套选好的模型。CommonBot 启动时发现它，就自己把运行时启动起来，并把对话、向量化、看图三类模型派好用场，不需要联网，也不需要再做设置。

把 `compute` 文件夹放到下面任一位置：

- 和 `commonbot` 程序同一个文件夹里（Linux 上先放好再执行 `sudo ./install.sh`，它会一并装到 `/opt/commonbot`）；
- 数据文件夹里（见第 9 节；桌面版用这个位置）。

默认的一套约 35 GB，按 48 GB 内存的机器选的：日常对话 qwen3:14b、更强的备选 qwen3:30b、向量化 bge-m3、看图 qwen2.5vl:7b。「模型」页最上面会显示算力包的状态。如果这台机器上已经有 Ollama 在运行，CommonBot 直接用它，不会再启动一份。运行时的日志在数据文件夹的 `logs/compute.log`。

算力包由发布者在能上网的机器上生成（源码里的 `scripts/compute-pack.sh`），可以换成别的模型。

### 没有网络时怎么装模型

在一台能上网的机器上用 Ollama 拉取好模型，把它的模型目录整个拷到这台机器的同一位置即可：

- Linux：`/usr/share/ollama/.ollama/models`（以服务方式安装时）或 `~/.ollama/models`
- Mac：`~/.ollama/models`

拷完重启 Ollama，在 CommonBot 的「模型」页点「立即检测」，就能看到这些模型。

## 3. 第一次设置

打开「模型」页：

1. 上方列出了推理服务，状态应为「正常」并显示模型数量。连不上时按提示检查服务是否启动、地址是否正确。
2. 「知识库用的模型」里选好向量化模型和文字识别模型（没有可以先不选）。
3. 联网搜索默认用内置搜索，不需要设置；点「试搜一次」可以确认这台机器的网络能搜到结果。也可以改用自建的 SearXNG 或带密钥的搜索接口。
4. 想在本机模型不可用时有个后备，可以「添加推理服务」→ 类型选「云端」，填地址、密钥和默认模型。

## 4. 智能体

「智能体」页列出所有智能体。点进去就是对话，右上角的「配置」里可以改它的定义。

- **负责的任务 / 不负责的范围**：写得越具体，它越守规矩。遇到不归它管的问题，它会直说。
- **知识范围**：勾选它默认查哪些知识库文件夹。
- **回答依据**：不联网 / 知识库优先、不足时联网 / 每次都联网。
- **模型**：可以固定用某个模型；不固定时用对话里选的。
- **开场白、示例问题**：新对话里显示，点示例问题直接提问。

对话时，输入框下面可以：上传文件（只在这个对话里用，不进知识库）、临时改这次查哪些文件夹、临时开关联网、换模型。回答里的小数字是出处编号，点一下能看到原文。

## 5. 用对话生成智能体（建造师）

1. 打开「建造师」，点「开始」。
2. 回答它的问题：给谁用、解决什么问题、要依据哪些资料、哪些事不该做、语气和格式。可以上传样例或现有的话术。
3. 右边的草稿会随着对话自动填上。哪里不对，直接告诉建造师，或点「手动修改」——你亲手改过的内容，建造师之后不会覆盖。
4. 点「开始试答」：建造师出几道题，让草稿里的智能体回答，并判断答得对不对。不满意就继续调整再试。
5. 点「发布为智能体」。它会出现在「智能体」页，并有自己的链接和 API 密钥。

## 6. 知识库

「知识库」页左边是文件夹，可以多级。先「新建知识库」，再在里面建子文件夹、上传文档。

- 支持 PDF、Word（docx）、PowerPoint（pptx）、Excel、文本、Markdown、网页和图片。不支持旧版的 doc、ppt 和压缩包。
- 上传后在后台排队处理，表格里能看到进度；失败会写明原因，可以重试。
- 扫描件需要先在「模型」页选好文字识别模型。之前因为没有它而失败的文档，选好后会自动重新处理。
- 「检索测试」可以看一个问题会找到哪些片段。
- 「只在这个文件夹里问」可以直接针对当前文件夹（含子文件夹）提问。

知识库里找不到依据时，智能体会说没有找到，不会编。

## 7. 发布给别人用

在智能体的「配置」最下面点「发布」（需要先固定一个模型）。发布后得到：

- **链接**：别人打开就能和这个智能体对话，不需要访问码，也看不到你的其他内容。
- **API 密钥和接口地址**：兼容 OpenAI 的接口，现成的客户端和程序可以直接接入。调用示例：

```
curl http://主机地址:8600/v1/chat/completions \
  -H "Authorization: Bearer 你的密钥" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"你好"}]}'
```

「取消发布」后链接和密钥立即失效；「更换密钥」只让旧密钥失效。别的设备要用链接或接口，需要先打开局域网访问（下一节）。

## 8. 让其他设备访问

默认只有这台机器自己能用。在「系统与外观」里打开「允许其他设备访问」，页面会列出访问地址。其他电脑、手机用浏览器打开该地址，第一次输入访问码即可。

访问码在「系统与外观」里查看和更换，只能在运行 CommonBot 的这台机器上操作。更换后，其他设备需要重新输入。

## 9. 数据在哪里、怎么备份

所有数据在一个文件夹里：

- Linux：`~/.local/share/CommonBot`
- Mac：`~/Library/Application Support/CommonBot`

里面的 `commonbot.db` 是智能体、对话、知识库内容，`files` 是上传的原始文档。备份时先退出 CommonBot，再把整个文件夹拷走；恢复时拷回原位。启动时可以用 `--data-dir` 指定别的位置。

## 10. 升级

下载新版安装包，退出旧版，用新版覆盖程序文件即可（Linux 上重新运行 `sudo ./install.sh`）。数据文件夹不用动，新版会自动升级其中的数据。不要用旧版程序打开新版写过的数据。

## 11. 常见问题

- **提示连不上模型服务**：确认 Ollama 等服务在运行；在「模型」页点「立即检测」。
- **回答很慢**：大模型出字慢是正常的，可以换小一些的模型做日常问答。
- **PDF 无法入库，提示找不到 PDF 解析库**：安装包里的 `lib` 文件夹要和程序放在一起。
- **手机上打不开**：确认已打开「允许其他设备访问」，手机和主机在同一个网络里，地址用的是页面上列出的那个。
- **忘了访问码**：在主机上打开「系统与外观」查看，或在终端执行 `./commonbot --access-code`。
