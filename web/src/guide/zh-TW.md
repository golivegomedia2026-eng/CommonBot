# CommonBot 使用說明

CommonBot 讓你在自己的機器上建立智慧體：為它定義負責的任務，給它資料讓它照著回答，需要時讓它連網；也可以透過和「建造師」對話，把一個新的智慧體定義出來並發布給別人使用。所有資料都存放在你自己的機器上。

## 1. 安裝與啟動

### Spark 或其他 Linux 機器

1. 解壓縮安裝包，進入解壓出的資料夾。
2. 直接執行：`./commonbot`，然後在這台機器的瀏覽器裡開啟 `http://localhost:8600`。
3. 想讓它開機自動執行：`sudo ./install.sh`。它會把程式裝到 `/opt/commonbot`，並登記為系統服務（以你目前的使用者身分執行）。解除安裝用 `sudo /opt/commonbot/uninstall.sh`，你的資料不會被刪除。

機器沒有接螢幕時，在終端機裡開啟區域網路存取並檢視存取碼，然後從別的裝置存取（見第 8 節）：

```
./commonbot --lan on
```

（用 `install.sh` 裝成服務後，改用 `/opt/commonbot/commonbot --lan on`，再執行 `sudo systemctl restart commonbot`。）

### Mac

1. 解壓縮安裝包。
2. 第一次使用前，在「終端機」裡對解壓出的資料夾執行一次（否則系統會因為程式沒有簽章而拒絕開啟）：`xattr -dr com.apple.quarantine 資料夾路徑`
3. 按兩下資料夾裡的「Start CommonBot.command」，瀏覽器會自動開啟。

### 桌面版（選用）

除了上面的壓縮檔，還有帶視窗的桌面版：Linux 是 `.deb`（`sudo apt install ./CommonBot_版本_arm64.deb`），Mac 是 `.dmg`。開啟後它自己在背景執行服務並顯示介面；關掉視窗後服務繼續執行，從系統匣圖示的選單裡結束。資料和壓縮檔版本放在同一個位置，兩種用法可以互換，但不要同時執行兩份。

## 2. 準備模型

CommonBot 本身不帶模型，它連接你機器上的推論服務。最省事的是 Ollama：裝好後拉取模型即可，CommonBot 預設就連它（`http://127.0.0.1:11434/v1`）。vLLM、llama.cpp 等任何提供 OpenAI 相容介面的服務也可以，在「模型」頁新增。

建議準備三類模型：

| 用途 | 說明 | 沒有它時 |
| --- | --- | --- |
| 對話模型 | 必需。回答問題、建造師都靠它 | 無法對話 |
| 向量化模型 | 讓知識庫能「按語意」檢索，例如 bge-m3 | 只能按關鍵字檢索 |
| 看圖模型 | 辨識掃描件和圖片裡的文字 | 掃描件、圖片無法讀取 |

### 沒有網路時怎麼裝模型

在一台能上網的機器上用 Ollama 拉取好模型，把它的模型目錄整個複製到這台機器的同一位置即可：

- Linux：`/usr/share/ollama/.ollama/models`（以服務方式安裝時）或 `~/.ollama/models`
- Mac：`~/.ollama/models`

複製完重新啟動 Ollama，在 CommonBot 的「模型」頁點「立即檢測」，就能看到這些模型。

## 3. 第一次設定

開啟「模型」頁：

1. 上方列出了推論服務，狀態應為「正常」並顯示模型數量。連不上時依提示檢查服務是否啟動、位址是否正確。
2. 「知識庫使用的模型」裡選好向量化模型和文字辨識模型（沒有可以先不選）。
3. 需要連網時，在「連網搜尋」裡選搜尋服務並點「試搜一次」。
4. 想在本機模型無法使用時有個後備，可以「新增推論服務」→ 類型選「雲端」，填位址、金鑰和預設模型。

## 4. 智慧體

「智慧體」頁列出所有智慧體。點進去就是對話，右上角的「設定」裡可以修改它的定義。

- **負責的任務 / 不負責的範圍**：寫得越具體，它越守規矩。遇到不歸它管的問題，它會直說。
- **知識範圍**：勾選它預設查哪些知識庫資料夾。
- **回答依據**：不連網 / 知識庫優先、不足時連網 / 每次都連網。
- **模型**：可以固定使用某個模型；不固定時使用對話裡選的。
- **開場白、範例問題**：新對話裡顯示，點範例問題直接提問。

對話時，輸入框下方可以：上傳檔案（只在這個對話裡使用，不進知識庫）、臨時更改這次查哪些資料夾、臨時開關連網、更換模型。回答裡的小數字是出處編號，點一下能看到原文。

## 5. 用對話生成智慧體（建造師）

1. 開啟「建造師」，點「開始」。
2. 回答它的問題：給誰用、解決什麼問題、要依據哪些資料、哪些事不該做、語氣和格式。可以上傳範例或現有的話術。
3. 右邊的草稿會隨著對話自動填上。哪裡不對，直接告訴建造師，或點「手動修改」——你親手改過的內容，建造師之後不會覆蓋。
4. 點「開始試答」：建造師出幾道題，讓草稿裡的智慧體回答，並判斷答得對不對。不滿意就繼續調整再試。
5. 點「發布為智慧體」。它會出現在「智慧體」頁，並有自己的連結和 API 金鑰。

## 6. 知識庫

「知識庫」頁左邊是資料夾，可以多層。先「新增知識庫」，再在裡面建子資料夾、上傳文件。

- 支援 PDF、Word（docx）、PowerPoint（pptx）、Excel、文字檔、Markdown、網頁和圖片。不支援舊版的 doc、ppt 和壓縮檔。
- 上傳後在背景排隊處理，表格裡能看到進度；失敗會寫明原因，可以重試。
- 掃描件需要先在「模型」頁選好文字辨識模型。之前因為沒有它而失敗的文件，選好後會自動重新處理。
- 「檢索測試」可以看一個問題會找到哪些片段。
- 「只在這個資料夾裡問」可以直接針對目前的資料夾（含子資料夾）提問。

知識庫裡找不到依據時，智慧體會說沒有找到，不會編造。

## 7. 發布給別人使用

在智慧體的「設定」最下方點「發布」（需要先固定一個模型）。發布後得到：

- **連結**：別人開啟就能和這個智慧體對話，不需要存取碼，也看不到你的其他內容。
- **API 金鑰和介面位址**：相容 OpenAI 的介面，現成的用戶端和程式可以直接接入。呼叫範例：

```
curl http://主機位址:8600/v1/chat/completions \
  -H "Authorization: Bearer 你的金鑰" \
  -H "Content-Type: application/json" \
  -d '{"messages":[{"role":"user","content":"你好"}]}'
```

「取消發布」後連結和金鑰立即失效；「更換金鑰」只讓舊金鑰失效。別的裝置要使用連結或介面，需要先開啟區域網路存取（下一節）。

## 8. 讓其他裝置存取

預設只有這台機器自己能用。在「系統與外觀」裡開啟「允許其他裝置存取」，頁面會列出存取位址。其他電腦、手機用瀏覽器開啟該位址，第一次輸入存取碼即可。

存取碼在「系統與外觀」裡檢視和更換，只能在執行 CommonBot 的這台機器上操作。更換後，其他裝置需要重新輸入。

## 9. 資料在哪裡、怎麼備份

所有資料在一個資料夾裡：

- Linux：`~/.local/share/CommonBot`
- Mac：`~/Library/Application Support/CommonBot`

裡面的 `commonbot.db` 是智慧體、對話、知識庫內容，`files` 是上傳的原始文件。備份時先結束 CommonBot，再把整個資料夾複製走；還原時複製回原位。啟動時可以用 `--data-dir` 指定別的位置。

## 10. 升級

下載新版安裝包，結束舊版，用新版覆蓋程式檔案即可（Linux 上重新執行 `sudo ./install.sh`）。資料夾不用動，新版會自動升級其中的資料。不要用舊版程式開啟新版寫過的資料。

## 11. 常見問題

- **提示連不上模型服務**：確認 Ollama 等服務正在執行；在「模型」頁點「立即檢測」。
- **回答很慢**：大模型出字慢是正常的，可以換小一些的模型做日常問答。
- **PDF 無法入庫，提示找不到 PDF 解析庫**：安裝包裡的 `lib` 資料夾要和程式放在一起。
- **手機上打不開**：確認已開啟「允許其他裝置存取」，手機和主機在同一個網路裡，位址用的是頁面上列出的那個。
- **忘了存取碼**：在主機上開啟「系統與外觀」檢視，或在終端機執行 `./commonbot --access-code`。
