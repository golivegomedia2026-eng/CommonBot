# 发行说明

## 一个发行版里有什么

| 附件 | 给谁 |
| --- | --- |
| `commonbot-<版本>-linux-arm64.tar.gz` | DGX Spark 等 ARM64 Linux |
| `commonbot-<版本>-mac-arm64.tar.gz` | Apple Silicon 的 Mac |
| `commonbot-<版本>-linux-x64.tar.gz` | 普通 x64 Linux |
| `CommonBot_<版本>_arm64.deb`、`CommonBot_<版本>_amd64.deb` | 桌面版（Linux）：带窗口和托盘，进程内运行服务 |
| `CommonBot_<版本>_aarch64.dmg` | 桌面版（Mac） |
| `policy.json`、`policy.json.sig` | 升级检查读的版本策略和它的签名（配置了签名密钥才有） |
| `SHA256SUMS` | 以上文件的校验和 |

每个包解压即用：程序（界面已内嵌）、PDF 解析库、四种语言的使用说明、第三方许可文件；Linux 包另有安装/卸载脚本，Mac 包有双击启动脚本。包里不含模型。

## 怎么发

1. 改版本号：`Cargo.toml` 的 `[workspace.package] version` 和 `web/package.json` 的 `version`，两处一致；提交并推送。
2. 在 GitHub 的 Actions 页运行 **Release** 工作流，填版本号和更新说明。
3. 工作流在三个平台上各自：跑测试、构建、打包，并把包解压到干净目录启动一次（确认版本号、界面、PDF 解析库都对）。全部成功后汇总成一个**草稿**发行版。
4. 下载草稿里的包，在真机上验证（见下）。没问题后在 GitHub 上把草稿公开；或者第 2 步勾选 `publish` 直接公开。

失败时草稿留着，修好后用同一个版本号重跑即可（会覆盖草稿里的附件）。已经公开的版本不会被覆盖，要修问题请发新版本。

## 升级检查与强制升级

程序启动后不久、之后每 6 小时，从最新发行版读取 `policy.json`，用编进程序的公钥验签，通过后才采信：

- 有新版本：界面顶部提示，可以「以后再说」。
- 当前版本低于 `minimum`：弹出关不掉的对话框，只能去下载新版。
- 没网、验签不过：不改变已有状态，绝不因此强制。

安装仍由人来做：下载新包、替换程序文件（Linux 上重新运行 `sudo ./install.sh`）。

### 第一次发行前要做的事（只做一次）

升级检查需要一对签名密钥。**没有做这一步的发行版不带升级检查，以后也无法对它们强制升级**（只能请用户手动装一次带检查的版本）。

1. 生成密钥对：

   ```bash
   cargo run -p commonbot-sign -- keygen
   ```

2. 把输出的公钥存为 `packaging/update.pub`，提交进仓库。
3. 把输出的私钥存为仓库的 Actions secret，名称 `COMMONBOT_SIGNING_KEY`；同时在仓库之外另存一份备份。私钥丢了，就再也无法给已发出去的版本签发升级策略。
4. 之后的发行版都会带上公钥，工作流会自动签名并核对私钥与公钥是否成对。

### 强制升级

- 临时强制到本次版本：运行 Release 工作流时勾选 `force`。
- 长期的最低版本：改仓库根目录 `update-policy.json` 里的 `minimum`。
- 撤销强制：发布一个更高的版本并把 `minimum` 调低；不要删除已发的版本。

## 发行前在真机上验证什么

自动检查覆盖不到的部分，每个目标平台至少做一次：

- 解压、启动、打开界面；`sudo ./install.sh` 后重启机器，服务自动起来（Linux）。
- 连上真实的推理服务：对话、带思考过程的模型的显示、出字速度。
- 知识库：上传真实文档（含扫描件），向量化和文字识别用真实模型跑通，提问得到带出处的回答。
- 打开局域网访问，另一台设备凭访问码使用；发布一个智能体，用链接和 API 密钥各访问一次。
- 从上一个版本升级：数据保留，对话和知识库都在。

## 桌面版

`apps/desktop` 是一个 Tauri 2 外壳：在进程里直接运行服务，开窗口显示界面，托盘常驻。本机 8600 端口上已经有 CommonBot 在运行时（比如装成了系统服务），它只开窗口连过去，不再启动第二份。

本地构建（Linux 需要先装窗口开发库）：

```bash
sudo apt-get install -y libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev libxdo-dev libssl-dev
```

```bash
scripts/desktop.sh
```

发行工作流里桌面版单独一个作业，失败不挡住离线包的发行。桌面版的升级提示与离线包相同（界面里提示，去下载页取新包安装），没有接入自动安装。

## 目前没有的

- 程序没有做系统签名和公证：Mac 上首次运行压缩包版需要先解除隔离（使用说明里有命令）；DMG 同样未签名。
- 没有手机客户端的安装包：手机用浏览器访问主机（界面已适配手机宽度）。
- 没有语音。
